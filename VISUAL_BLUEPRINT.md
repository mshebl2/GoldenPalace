## 2. Layout Geometry & Hierarchy

### Container System
- Maximum Content Width: `1240px` (centered).
- Responsive Gutters: `16px` on mobile, `24px` on tablet, `32px` on desktop.
- Section Spacing:
  - Top Bar: `34px` height
  - Navigation: `70px` height
  - Hero: Full-width container, height approx `500px` - `540px` on desktop
  - Section vertical padding: `56px` to `72px`
  - Gap between cards: `16px` to `20px`
