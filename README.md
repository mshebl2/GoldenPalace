# القصر الذهبي للدهانات والديكورات الحديثة
## Premium Arabic Website — Al Qasr Al Dhahabi Paints & Decors

موقع إلكتروني متكامل وعالي الجودة لشركة **القصر الذهبي للدهانات والديكورات الحديثة** بالمنطقة الشرقية (الخبر، الدمام، القطيف). تم بناؤه بأحدث تقنيات الويب الحديثة ليعكس الفخامة والهوية البصرية المعتمدة بدقة بكسل-متناهية، مع ربط مباشر لكافة العروض بنظام محادثات واتساب التفاعلي لزيادة معدل تحويل الزوار إلى عملاء فعليين.

---

## 🌟 أبرز مميزات المشروع

- **مطابقة الهوية البصرية**: كحلي داكن ملكي (`#081B33` / `#061426`) مع تدرجات ذهبية عصرية وألوان نصوص واضحة ومريحة للعين.
- **عروض الأسعار المعتمدة**:
  - عرض الغرفة: 500 ريال (بدل 700 ريال)
  - عرض غرفتين: 700 ريال (بدل 1000 ريال)
  - عرض 3 غرف: 1000 ريال (بدل 1300 ريال)
  - عرض السقف: 100 ريال
  - عرض الباب: 90 ريال
  - بنود العرض الخمسة: معالجة أركان الجدران بالمعجون، وجه سنفرة، وجه أساس، وجهين تشطيب، مع نظافة مكان العمل.
  - نوع الصبغ: **JOTUN (جوتن)** الأصلية.
- **تكامل واتساب المباشر**: رسائل ذكية مجهزة ومخصصة لكل باقة وخدمة ونموذج عرض سعر بدون باك إند وهمي.
- **صفحات متكاملة (10 صفحات + صفحات ديناميكية)**:
  - الرئيسية (`/`)
  - من نحن (`/about`)
  - خدماتنا (`/services`)
  - تفاصيل الخدمات (`/services/[slug]`) لـ 6 خدمات متخصصة
  - أعمالنا (`/portfolio`) مع فلترة تصنيفات وعارض صور مكبر (Lightbox)
  - العروض الحالية (`/offers`)
  - المدونة المعمارية (`/blog`) وتفاصيل المقالات (`/blog/[slug]`)
  - تواصل معنا (`/contact`) مع خريطة توضيحية ونموذج معتمد
  - سياسة الخصوصية (`/privacy`)
  - صفحة 404 مخصصة (`/not-found`)
- **تصميم متجاوب 100%**: تجربة سلسة على الجوال، التابلت، والكمبيوتر، مع شريط علوي وهيدر لاصق وقائمة جوال جانبية وزر واتساب عائم.
- **SEO محلي متقدم**: Schema.org JSON-LD، خريطة موقع Sitemap.xml، ملف Robots.txt، ميتا تاج عربية تستهدف كلمات البحث بالخبر والدمام والقطيف.

## 🛠️ البنية التقنية المستخدمة

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Typography**: Google Font (Tajawal)
- **Icons**: Lucide React
- **Motion**: Framer Motion
- **Form Validation**: React Hook Form + Zod
- **Image Optimization**: next/image + sharp

## 🚀 طريقة التشغيل محلياً

```bash
# تثبيت الحزم (إن لم تكن مثبتة)
npm install

# تشغيل بيئة التطوير
npm run dev

# أو بناء وتشغيل نسخة الإنتاج
npm run build
npm run start
```

الموقع سيعمل مباشرة على: `http://localhost:3000`

## 🌐 النشر على Vercel

المشروع جاهز تماماً للنشر على منصة Vercel بنقرة واحدة:
1. اربط مستودع GitHub بحساب Vercel.
2. سيقوم Vercel تلقائياً باكتشاف Next.js وتشغيل `npm run build`.
3. لا يتطلب المشروع أي متغيرات بيئة إجبارية في الإصدار الحالي.
